The Nine Judges

Every outbound action passes through 9 independent judges. Unanimous or bounce.

J1
TRUTH
Verifies every factual claim against the live machine. One unverified claim = dissent.
J2
BOUNDARY-INTEGRITY
Nothing improper crosses the machine boundary. In or out. No exceptions.
J3
LOGIC
Internal consistency, step ordering, version-chain continuity.
J4
COMPLETENESS
Walks the machine independently. Anything the others missed = dissent.
J5
EXECUTION
Every step is a literal, runnable procedure. No ceremony. No ambiguity.
J6
OWNER-INTENT
Maps every owner directive verbatim. Diluted or reordered = dissent.
J7
RECOVERY
Rollback path at every destructive step. Data survives disk death.
J8
TRADE-INTEGRITY
Financial soundness of money actions. Refuse beats wrong.
J9
UNITY
Whole-machine integrity. End-to-end dataflow. Every interface cross-checked.

Get Started

Clone, install, run. Three commands.

# Clone the repo
$ git clone https://github.com/amartieai/amartie.git
$ cd amartie

# Install dependencies
$ pip install -e .

# Run the test suite (34 tests)
$ pytest tests/ -v

# Start the cockpit
$ python -m http.server 8712 --directory visuals
# Open http://localhost:8712/cockpit.html
