# AMARTIE 30-day community plan

The goal is conversion, not vanity traffic: a reader should move from README to security/architecture docs and then to a claimed issue, PR, or Discussion.

## Day 1

- Push the community landing pack to `main`.
- Create the priority labels and project board.
- Pin the chain, dry-run plugin, and Windows documentation issues.
- Enable private vulnerability reporting.
- Publish one factual Announcement post.
- Do not announce until `main` matches the README.

## Week 1: establish the funnel

Make one external post that says: local gate, nine judges, fail closed, alpha, and three concrete issues. Watch whether readers move from README to `SECURITY.md`, `docs/ARCHITECTURE.md`, and the issue tracker.

## Week 2: remove friction

Respond to questions within 48 hours. If README traffic exists but issues remain empty, shorten the call to action and improve issue context; do not add more architecture prose.

## Week 3: show verifiable movement

Merge one visible improvement or explain why it is not ready. Publish one PASS receipt and one DISSENT receipt without real addresses, keys, or public binds. Never stage a demo that claims behavior the code does not implement.

## Week 4: measure community, not owner activity

Count unique non-owner issue reporters, non-owner PRs, Discussions, and successful local runs. Owner-only commits are maintenance, not community traction.

## What to measure

- README unique views and returning visitors
- clicks into SECURITY, architecture, and roadmap pages
- issue views and new non-owner reporters
- forks, non-owner PRs, and Discussions
- time from first question to maintainer response

Traffic is attention. Issues, PRs, and Discussions are conversion. A flat traffic graph is not automatically bad; traffic without contribution is the signal to fix the funnel.

## Public language

Do not call AMARTIE a production security framework. Say: **“AMARTIE is a local-first alpha gate with nine judges, fail-closed behavior, and auditable receipts.”** Keep the known limitations visible.
