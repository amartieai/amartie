# MARTIE Grant Application Skeleton

## One-line pitch
Open forensic engine proving whether a provider served the model a user was billed for.

## The problem
Silent model swaps are invisible to users.

## The solution
Read session dumps, compare billed vs returned model strings, and emit replayable receipts.

## Evidence
- Fixtures: pass.json, fail.json
- Schema frozen at v1.0
- Hash-chained, stranger-verifiable receipts

## Ask
12–24 months: kernel gate, cross-platform support, independent audit, public corpus.
