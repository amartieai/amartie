Activated

Node 01 — Gate Armed

The gate is online and monitoring. All nine judge seats are filled with assigned models. No action passes without unanimous review. The core pulses when a task enters the pipeline.

Core energized
9 seats filled
Ready for intake

Multi-Agent

Node 02 — Judge Mesh

Nine independent judges orbit the task. Each seat is model-locked — a judge cannot sign with a different model than assigned. No single point of failure. No silent substitution.

Model-locked seats
Daily rotation
Unanimous required

Accountability

Node 03 — Hash-Chained Receipts

Every action produces a receipt. SHA-256 over canonical sorted JSON. Each receipt links to the previous. Tamper one character, the chain breaks. Stranger-verifiable.

SHA-256 canonical
Chain-linked
Replay verifiable

Rejection

Node 04 — The Barrier

One dissent refuses the action. The receipt is preserved as evidence — not deleted. Corrections can be re-judged up to four rounds. Endless retry is not allowed.

1 dissent = bounce
Round cap: 4
Receipt preserved

Task

Node 05 — Payload Intake

The action being proposed — email send, tool call, webhook, generation. The payload is SHA-256 hashed before review. What gets hashed is what gets judged. No bait-and-switch.

SHA-256 sorted JSON
Scope declared
Immutable after hash

Intercepting

Node 06 — Interception Point

The gate sits between the studio and the outbound action. Every side effect is intercepted before it leaves. Nothing calls a provider before verify_action. The bot + data meet at this checkpoint.

Pre-send interception
verify_action gate
No bypass path

Embargo

Node 07 — Process Frozen

Until the gate clears, the action is frozen. No partial sends. No silent failover. No hidden swaps. The embargo lifts only on unanimous PASS. The clock runs until the verdict lands.

Zero partial sends
No silent failover
Lifts on unanimous PASS
